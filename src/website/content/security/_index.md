title: Security Advisories
description: Details of security advisories for http4k libraries
---

This page lists http4k security advisories that have been assigned a CVE identifier.

Not every advisory receives a CVE. All confirmed vulnerabilities - with or without a CVE - are published as GitHub Security Advisories against
the [http4k repository](https://github.com/http4k/http4k/security/advisories), and are carried by the GitHub Advisory Database, OSV and Dependabot. Our criteria
for requesting a CVE are set out in the [Coordinated Vulnerability Disclosure Policy](/cvd-policy/).
